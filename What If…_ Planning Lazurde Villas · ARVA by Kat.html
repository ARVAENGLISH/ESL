GOAL

Today's goal 🎯

By the end of this class, you can explain the rules, risks and possible scenarios of your project using IF.
  • ✅ Use the zero conditional for site rules and procedures: If it is 12:00, nobody works outside.
  • ✅ Use the first conditional for possible future situations: If it rains on Tuesday, the pour will move to Wednesday.
  • ✅ Use if vs when correctly in a planning meeting.

STEP 3 · INPUT⏱ 8 min

Site briefing 📋

Read the planning engineer's briefing about the yard plan and the pouring cycles. Then answer True or False.

From: Planning Engineer, TBG – Techno Build Group
To: Site team · Lazurde Villas, Al Khobar
Subject: Yard plan & pouring cycles: what you need to know

Good morning, team! Here is a short summary of our Temporary Facilities & Formwork Yard Plan.

🏗️ Our yard

Our TBG facilities cover 5,368 m². The biggest area is the rebar yard (1,500 m²), and the second is the main warehouse (1,400 m²). The formwork yard is 1,200 m², and the washing bay is right next to it. If panels have concrete residue, we wash them before storage. If a forklift moves between the washing bay and the yard, the trip is very short.

☀️ Hot season

From 15 June to 15 September there is a legal rule: if the time is between 12:00 and 15:00, nobody works outside. If workers need a break, they go to one of our 6 shaded shelters with water and cooling. We pour concrete at night because if we pour after 20:00, there is less thermal stress on the concrete and on the workers.

🌧️ Cold season

Be careful with the weather. If it rains heavily on a pour day, the pour will move one or more days. We use self-leveling concrete, and one mixer arrives every 15 minutes.

🌙 Ramadan

During Ramadan, the main trades work at night. If it is between 08:00 and 20:00, the contractor shift is closed, so all trades must hand over before 08:00.

🚜 Logistics

The trade order is fixed: Formwork → Rebar → Electrical. If formwork doesn't hand over, rebar doesn't start. Next month we may increase the rhythm. If we stay at one cycle per day, we will need 5–6 telehandlers. If we move to two cycles per day, we will need 8–10. And remember: if material movement doesn't keep pace with the crews, the line will stop. If the on-site concrete plant has a problem, we won't meet the schedule.

Production starts on 16 May 2027. Let's be ready! 💪

True or False?

👩‍🏫 Notas para la profe

  • Pregunta extra de conexión: "Is your real site similar? What's different?"

STEP 4 · DISCOVERY⏱ 5 min

Find the pattern 🔍

Look at these sentences from the briefing. Is it a rule / procedure (always true) or a possible future situation?

Now, you're the detective 🕵️‍♀️

1. In the rules, which tense comes after if? And in the other part of the sentence?

2. In the possible future sentences, which tense comes after if? And in the other part?

3. Do we ever see will right after if?

4. Look at the comma (,). When do we use it?

1. Rules: if + present simple → present simple.
2. Possible future: if + present simple → will / won't + verb.
3. No! We don't use will after if. ✗ If it will rain → ✓ If it rains.
4. We use a comma when the if-part comes first: If it rains, the pour will move. / The pour will move if it rains.
👩‍🏫 Notas para la profe
  • Deja que ella llegue sola a la regla; tú solo haces preguntas guía.
  • Clave: rule = "every time / always" · future = "maybe, one specific situation".
STEP 5 · GRAMMAR⏱ 7 min

Zero vs First Conditional 🐍

0️⃣ Zero conditional

Use it for: rules, procedures, facts. It's always true.

If + present, present
If the time is 12:00–15:00 in summer, nobody works outside.
If panels have residue, we wash them.
If formwork doesn't hand over, rebar doesn't start.

1️⃣ First conditional

Use it for: a real, possible future situation: risks, scenarios, Plan B.

If + present, will / won't + verb
If it rains on Thursday, the pour will move to Friday.
If we move to 2 cycles a day, we will need 8–10 telehandlers.
If the plant stops, we won't meet the schedule.

💡 IF or WHEN?

IF = maybe 🤔WHEN = sure, it's in the schedule 📅
If it rains on Thursday, we will delay the pour.When the formwork crew finishes at 03:00, the rebar crew will start.
If the consultant rejects the rebar, we will fix it before 09:00.When production starts in May 2027, the yard will be ready.

🚩 Common mistakes

✗ If it will rain, we will delay the pour.
✓ If it rains, we will delay the pour.
✗ If we need a faster pour, we use 2 pumps tomorrow.
✓ If we need a faster pour tomorrow, we will use 2 pumps.
✗ If the plant don't work…
✓ If the plant doesn't work…

Contractions in meetings: we will → we'll · will not → won't · it will → it'll

👩‍🏫 Notas para la profe
  • Contraste con español: "Si llueve, se retrasará": igual que en inglés, presente después de "si". Ayuda a evitar if it will.
  • IF vs WHEN es clave para una planeadora: lo programado va con when; los riesgos, con if.
  • Practica la pronunciación de we'll / won't (want ≠ won't).

C. The domino effect 🁢

In planning, one problem causes the next one. Complete the chain with first conditional sentences.

If it rains heavily on Tuesday, the pour will move to Wednesday.

If the pour moves to Wednesday, …

If the curing starts late, …

If …, …

If …, …

If the pour moves to Wednesday, the curing will start one day late. → If the curing starts late, we won't strip the formwork on time. → If we don't strip the formwork on time, the next villa won't start its assembly. → If the next villa doesn't start, we will need to recover the day with two cycles.
👩‍🏫 Notas para la profe
  • A y B se autocorrigen; pide que lea cada frase en voz alta con contracciones.
  • C es la parte más productiva: déjala usar su experiencia real; corrige solo la estructura.
