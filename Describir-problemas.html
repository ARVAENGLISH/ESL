6. LOOK — SO NOW WHAT? AFTER THE EARTHQUAKE

In August 2026, a strong earthquake hit Colombia. Engineers and authorities had to inspect buildings and construction sites after the event.

After an earthquake, engineers need to check for cracks, damage, and structural problems. They also need to check the foundation and the ground under the building.

But why do some buildings have serious damage while others do not?

One important factor is the type of soil. Some buildings are on soft ground, while others are on harder ground. The soil can include clay, sand, or rock, and these conditions can affect the stability of a building.

If engineers find serious problems, construction may need to stop. A project can be delayed because engineers need more information about the soil or the structure.

Workers may have to wait while engineers do more tests and inspect the building.

After an earthquake, the next step is not always to continue construction. First, engineers need to understand the problem, the cause, and the possible result. Then they can decide what action to take.

Engineers need to do more tests.

PROBLEM → CAUSE → RESULT → ACTION

8. GRAMMAR

🟣 THERE IS / THERE ARE

There is + singular

There is a problem with the soil.

There are + plural

There are cracks in the wall.

🟠 BECAUSE

Use because + subject + verb.

The project is delayed because the soil is soft.

🟢 BECAUSE OF

Use because of + noun / noun phrase.

The project is delayed because of the soft soil.

❌ because of the soil is soft

✅ because the soil is soft

✅ because of the soft soil

🔵 SO

Use so to explain a result or consequence.

The soil is soft, so the project is delayed.

🔴 NEED TO

Use need to + base verb to talk about a necessary action.

Engineers need to check the foundation.
We need to do more soil tests.

❌ need to checking

❌ need to checked

✅ need to check

PROBLEM → CAUSE → RESULT → ACTION

So, construction must stop.
Engineers need to inspect the building.
